Proofs of payment

When a client you're chasing says they've already paid, ask them for a proof of payment (POP) and upload it here.
If you know which invoice it's for, put the invoice number in the file name, for example HN-0003 Peter.pdf.

The head coach's POP recon picks it up from here. When it's matched, the invoice drops off your unpaid list.
Only you and the head coach can see this folder. Don't delete POPs once uploaded.
